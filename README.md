# Rinha de Backend 2026 — Exemplo Clojure

Exemplo de submissao para a [Rinha de Backend 2026](https://github.com/zanfranceschi/rinha-de-backend-2026).

## Stack

- **API:** Clojure (Ring/Compojure) — 2 instancias

- **Porta:** 9999

## Como rodar

```bash
docker compose up -d
```
